# Personal Portfolio Website

A personal portfolio website developed to showcase my profile, technical skills, services, and web development interests. The website includes an introduction, about section, services, skills, blog, and contact form.

## Project Overview

This project was developed as part of my front-end development practice during the CodSoft internship. It demonstrates the use of core web technologies to create a personal portfolio website.

## Features

- **Home Section** – Introduction and profile presentation
- **About Section** – Personal information and background
- **Services Section** – Overview of development services and interests
- **Skills Section** – Highlights technical skills
- **Blog Section** – Displays content about web development and design
- **Contact Section** – Contact form interface
- **CV Section** – Download CV option
- **Navigation Menu** – Links to different sections of the website

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome Icons

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Ensure the HTML, CSS, JavaScript, and image files are available.
4. Open `protofolio.html` in a web browser.

No additional installation is required.
